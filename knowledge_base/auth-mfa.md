# Двухфакторный вход MFA

## Проверка кода
MFA использует шестизначные TOTP-коды из приложения-аутентификатора. Код меняется каждые 30 секунд. При MFA_INVALID включите автоматическую синхронизацию даты и времени на телефоне, выберите запись TeamSpace для нужного аккаунта и дождитесь нового кода.

## Потерянный телефон
Если приложение недоступно, используйте один из сохранённых резервных кодов. Каждый код одноразовый. Не отправляйте TOTP, QR-код настройки или резервные коды в чат. Сотрудник поддержки не должен запрашивать эти секреты.

## Восстановление
Если нет ни приложения, ни резервных кодов, обратитесь в поддержку для отдельной процедуры проверки владения аккаунтом. Учебный ассистент не отключает MFA и не подтверждает личность. MFA доступна на Free, Team и Business; изменение тарифа не решает ошибку времени на телефоне.
