# Обзор TeamSpace

## Назначение
TeamSpace 1.0 — синтетический сервис совместной работы: пространства, проекты, задачи, комментарии и вложения. Пользователь может состоять в нескольких пространствах. Тариф и роль назначаются отдельно для каждого пространства; наличие аккаунта само по себе не даёт доступ к чужому проекту.

## Первые шаги
Подтвердите email, создайте пространство или примите приглашение, затем откройте проект и создайте задачу. Если приглашение не открывается, сохраните показанный код ошибки. Перед обращением в поддержку укажите версию 1.0, действие и время ошибки с часовым поясом.

## Границы продукта
В 1.0 нет видеозвонков, криптовалютных платежей и автоматического исправления компьютера. Ассистент только читает документацию и тикеты: он не создаёт обращения, не меняет тариф и не выполняет действия в аккаунте. Данные учебного экземпляра не отражают состояние реальной системы.
